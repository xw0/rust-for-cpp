# Further reading

- [The Rust Programming Language](https://doc.rust-lang.org/book/) ("the
  Book"): the official introduction. Slower paced, assumes no C++.
- [Comprehensive Rust](https://google.github.io/comprehensive-rust/): Google's
  multi-day course, with a C++ interop section.
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/): short runnable
  examples by topic.
- [Learn Rust With Entirely Too Many Linked Lists](https://rust-unofficial.github.io/too-many-lists/):
  ownership, `Box`, `Rc` and `unsafe` through one data structure.
- [The Rustonomicon](https://doc.rust-lang.org/nomicon/): the guide to
  `unsafe` Rust.
- [Rust Atomics and Locks](https://marabos.nl/atomics/) by Mara Bos: low-level
  concurrency, for readers who know the C++ memory model.
- [Learn wgpu](https://sotrh.github.io/learn-wgpu/): a graphics tutorial using
  wgpu.
- [Are we game yet?](https://arewegameyet.rs/): the Rust game development
  ecosystem.
